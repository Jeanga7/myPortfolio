# The Living Signature

Socle initial du portfolio de Jean Gabriel Goudiaby.

## Développement

Utiliser Bun :

```sh
bun install
bun run dev
```

Contrôles disponibles : `bun run lint`, `bun run typecheck` et `bun run build`.

Les dossiers d’images sont réservés aux assets validés. Aucun Hero ni composant définitif
n’est inclus dans cette itération.
